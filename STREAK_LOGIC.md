# Streak Logic Explanation

Your streak (Ripeness Level) works as follows:

## Core Rules
1.  **Strict Consecutive Days**: You must engage with the challenges every day to keep your streak alive.
2.  **Partial Save**: Completing **at least 1** challenge saves your streak for the day (prevents it from resetting).
3.  **Growth**: Your streak **only increments** when you complete **ALL 3** Daily Challenges (Newspaper, Vocab, Perfect).
4.  **Reset**: If you do **not** complete any challenges on a given day, your streak resets to **0** the next time you play.
5.  **Starting**: Streaks start at 0. Completing all 3 challenges on your first day moves you to Streak 1.

## Examples
-   **Day 1**: 3/3 Challenges done ➔ Streak **1**.
-   **Day 2**: 1/3 Challenges done ➔ Streak **1** (Saved).
-   **Day 3**: 3/3 Challenges done ➔ Streak **2**.
-   **Day 4**: 0/3 Challenges done (Skipped).
-   **Day 5**: 3/3 Challenges done ➔ Streak **1** (Reset to 0, then incremented).

## Timezone
The "day" is based on the server time (UTC/ISO date), so be sure to finish before midnight!
